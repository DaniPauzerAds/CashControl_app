## Descrição

<p align="center">
<img src="imagens/screenshot.png" alt="CashControl App" border="0">
</p>

O CashControl é um aplicativo mobile desenvolvido  com o objetivo de ajudar o usuário a controlar seus gastos mensais de forma simples e intuitiva.
<br><br>
Com o CashControl é possível criar uma conta, fazer login e registrar despesas organizadas por categoria, tendo uma visão clara de para onde seu dinheiro está indo.
<br><br>

## 🛠 Estrutura de pastas

Há 4 pastas que seguem da seguinte forma:

<b>documentos</b>: Toda a documentação estará nesta pasta.

<b>executáveis</b>: Binários e executáveis do projeto devem estar nesta pasta.

<b>imagens</b>: Imagens do sistema.

<b>src</b>: Pasta que contém o código fonte.

## 🛠 Instalação

<b>Android:</b>

Faça o download do CashControl.apk no seu celular.
Execute o APK e siga as instruções do seu telefone.

```sh
Não é necessário nenhum comando adicional.
```

## 💻 Configuração para Desenvolvimento

Para rodar este projeto você precisará das seguintes ferramentas:

- <a href="https://developer.android.com/studio">Android Studio</a>
- <a href="https://nodejs.org/">Node.js</a>

```sh
cd src/backend
npm install
node index.js
```
